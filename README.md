# School WiFi Connect

[下载最新版](https://github.com/li-zane/school-wifi-connect/releases/latest)

解压 Windows-x64.zip 后运行 `NJUSTWiFi.exe`，无需安装 Python；使用系统的 Edge WebView2 Runtime。请把整个目录放在自己可写的位置。

右上角“检查更新”支持检查正式发布、下载校验、安装并重启。新版本启动失败会自动恢复旧版。旧于 3.7.0 的版本需先手动下载一次。

账号、密码、备用网络与日志仅保存在 `%LOCALAPPDATA%/NJUSTWiFi`，不上传 GitHub；分享时只分享发布 ZIP。

## 在线发布

修改 `njust_wifi/__init__.py` 版本并推送对应 `vX.Y.Z` 标签，GitHub Actions 会执行测试、构建并发布 Windows ZIP、源码 ZIP 和 `SHA256.json`。更新只在用户点击时检查，安装在可写目录中进行，并保留原版本备份。源码运行支持检查版本，应用内安装需使用桌面发布版。


轻量 Windows 校园网自动登录工具。Python 标准库后端、原生 HTML/CSS/JavaScript 界面和 Windows 原生托盘/窗口。使用系统 WebView2，不附带 Chromium、Node.js 或数据库。

## 使用

Windows 10/11 x64 发布包完整解压后双击 `NJUSTWiFi.exe`，打开独立桌面窗口。需要系统已有 Microsoft Edge WebView2 Runtime 与 .NET Framework 4.6.2 或更新版（当前 Windows 通常已包含）。后端固定监听 `http://127.0.0.1:18089`，也可从浏览器访问。

关闭或最小化窗口会退出整个网页窗口进程，保留轻量托盘与后台；双击托盘或再次打开 EXE 可重开窗口。托盘“退出界面”退出托盘和窗口，保留网络监控；“退出程序”同时停止后台。后端通过当前用户的 Windows 任务计划程序独立运行，不依赖桌面窗口。“开机启动”和“启动后自动监控”分别控制 Windows 登录后启动后台、后台启动后开始检测。在界面关闭开机启动仅移除登录触发，不中断当前后台。

监控开启并已配置网络时，检测到 WiFi 软件开关关闭会自动尝试开启，再按校园网、备用列表的原顺序恢复连接。WiFi 已开启时只读取状态，不重复设置；正常状态不新增开关日志。开启失败后按 30 秒、1 分钟、2 分钟、4 分钟、5 分钟退避重试，此后最长每 5 分钟重试；也可点“立即检测”。需要保持 WiFi 关闭时，先暂停监控。硬件开关关闭、无线网卡被禁用或系统拒绝设置时显示简短提示，保留原状态并稍后重试；程序不修改飞行模式总开关、不启用被禁用的网卡。开关恢复调用 Windows WLAN API，不新增依赖或常驻轮询线程。

设置中的 `NJUST WIFI` 是校园网 SSID，默认仍为 `NJUST`。它留空或未配置校园账号时，只使用备用 WiFi。备用列表最多 8 项，可添加、删除和上下调整顺序；检测恢复时先尝试校园网，再按列表顺序尝试备用网络，每项失败继续下一项。备用网络运行正常时，后续周期仍会尝试恢复更高优先级的网络。

备用密码填写后通过 Windows WLAN API 在内存中创建当前用户的 WPA2-Personal/AES 网络配置，不生成含密码的临时 XML 文件。密码应为 8–63 位 ASCII 字符或 64 位十六进制密钥；密码留空复用 Windows 已有网络配置，其他认证类型请先在 Windows 中连接并保留密码为空。NJUST WIFI 账号与各备用密码会在设置页回填，备用密码默认可见，可点眼睛按钮隐藏；校园密码可点眼睛按钮显示。应用中未填写备用密码时，设置页仅按已配置的 SSID 读取 Windows 保存的密码显示，不导出 XML，也不因显示而把密码写入应用配置；Windows 未保存或未授予读取权限时保持空白。

高级设置中的“认证域”是学校认证接口用于区分账号所属域的字段，通常保留 `default`；NJUST WIFI 账号和密码是学校门户登录信息，与备用无线网络密码不同。认证服务器固定为 `m.njust.edu.cn`。

代理兼容按请求自动处理，无需手动开启。普通连接仍绕过系统 HTTP 代理；识别到常见 TUN 网卡、Fake-IP（`198.18.0.0/15`）或直连探测失败时，改用绑定物理 WiFi 网卡与源地址的连接，并向该网卡的 DNS 查询真实 IPv4。联网检测、程序内校园认证和余额查询共用这套分支，不需要打开网页，也不修改系统代理、路由、DNS 或其他应用的流量。HTTPS 保留原始域名和证书校验，认证超时不会在另一路径重复提交同一请求。

代理兼容通路不确定时会保留当前 WiFi，显示短提示并按现有失败退避稍后重试；学校只读接口确认已认证而外网探测失败时，也不会因此反复认证或切换备用网络。明确未认证后仍执行原认证流程，其他明确失败仍按备用列表顺序处理。该通路依赖 Windows 提供的物理 WiFi IPv4 与可用 DNS；TUN 的防火墙或阻断规则仍可能阻止网卡绑定连接，程序不会自动关闭代理。高级设置额外打开的系统浏览器页面仍遵循浏览器自己的代理设置，兼容分支只作用于本程序请求。

桌面界面参考 GPT Image API 的 `gpt-image-2.6` 设计图，由 Antigravity 的 Gemini 4 Hydrogen（XHigh）直接编写 HTML/CSS/JS 并完成美化；Codex 负责审查、交互回归、Bug 修复与打包。浅红侧栏、浅蓝工作区，状态页集中显示连接、余额与后台概览；设置、守护、日志各用独立内容空间。四页视口保持一致，长内容内部滚动；侧栏支持上下方向键，帮助按钮可重放新手引导，反馈为顶部居中 Toast。日志支持关键词与日期联合筛选，备用列表提供顺序图标按钮和数量提示。默认窗口为 1120×780，最小为 860×620，针对桌面缩放布局，不提供移动端界面。深色主题与自绘标题栏同步；标题栏支持拖动、缩放与最大化，最小化和关闭返回轻量托盘。面板不使用磨砂模糊，不引入字体下载、前端框架、大图背景或持续动画。品牌 WiFi 图形由可编辑 SVG 导出，侧栏、网页图标、标题栏、托盘和 EXE 统一使用淡红淡蓝标识；运行时只加载 96px WebP 和多尺寸 ICO，设计参考大图不加入运行包。

四页下方内容框随窗口高度统一布局，长设置、程序和日志在框内滚动。高级设置“认证时打开学校登录页”会在尝试校园网认证时额外打开系统浏览器，关闭后仍会自动认证。

首次使用且尚未配置网络时，界面会显示五步短引导：校园账号、备用 WiFi、保存、开始监控、程序守护。右上角问号可随时重新查看，支持跳过、上一步和 Esc 退出。引导只切换页面和定位控件，不自动保存设置、联网或启动程序；已有配置的用户不会自动弹出。

## 隐私

- 账号直接发送到学校门户，不经过作者服务器；无遥测、广告、在线字体、云端账号或远程前端资源。
- 默认校园凭据只保留在内存。“记住账号”将校园账号密码保存为本机 JSON；备用网络及其密码随设置保存为本机 JSON，不加密。配置和日志存放在 `%LOCALAPPDATA%\NJUSTWiFi`，发布包不包含这些个人数据。
- 设置页通过本地会话保护的 `/api/credentials` 读取真实校园账号密码，配置接口读取备用密码；状态和诊断接口不返回凭据。空校园账号和空校园密码保持原值，清除使用“清除账号密码”。浏览器存储只保存主题和新手引导完成/跳过标记，不保存凭据；桌面 WebView2 关闭密码自动保存与自动填充。
- 页面关闭或浏览器隐藏后停止前端轮询；后端按设定间隔休眠，失败时 30 秒起指数退避，最长 5 分钟。
- 日志仅保留固定状态消息，不记录门户响应正文、账号、密码、SSID、IP、MAC 或个人路径。磁盘日志最多约 768 KiB；界面只保留最近 100 条事件。
- 导出的诊断报告采用字段白名单，不包含配置、凭据或设备标识；可清除已保存凭据。
- 余额只向学校查询，先后核对在线账号与配置账号；只在内存缓存，不写入日志、诊断或分享包。联网检测成功后最多每 5 分钟自动刷新，也可手动刷新。离开校园网或账号不一致时显示查询状态；从未获取成功时显示“—”，零余额显示 0.00。
- 连通性探测默认访问微软/小米的公开检测端点，可在高级设置中修改。校园认证遵循现有门户 HTTP 协议；认证请求不跟随重定向。代理兼容分支在本机内存中使用网卡地址和 DNS，不将这些信息写入日志或诊断；诊断仅增加 `connection_path` 状态（`normal`、`wifi-direct` 或 `unavailable`）。

本地接口仅监听 `127.0.0.1`，通过主机、来源和会话令牌校验保护写操作；静态资源只允许固定路径。端口冲突直接报错，不自动换端口。

## 从源码运行

安装 Python 3.11 或更新版本。运行时没有第三方依赖。

```powershell
python -B app.py
```

本机日常使用双击 `Start-NjustWifi.pyw`，存在当前版本的桌面构建时打开桌面端；未构建时使用源码后端与浏览器。或用系统 Python 注册后启动：

```powershell
.\scripts\startup.ps1 -Mode Install -Executable (Get-Command pythonw.exe).Source
.\scripts\startup.ps1 -Mode Start
```

后台任务名 `NjustWifiLocalMonitor`，端口 `18089`，日志 `%LOCALAPPDATA%\NJUSTWiFi\events.jsonl`。仅停止：

```powershell
.\scripts\stop.ps1
```

移除任务：`.\scripts\startup.ps1 -Mode Remove`。该命令保留配置与账号。也可以通过任务管理器退出手动启动的 `NJUSTWiFi.exe`。界面“暂停”停止自动连接，但保留设置界面服务。

## 验证与发布

```powershell
python -B -m unittest discover -s tests -q
python scripts/build-release.py
```

构建 Windows 发布包只在开发环境安装 PyInstaller，然后执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe scripts/build-release.py --exe
```

采用目录式 EXE，避免每次启动将整个 Python 解压到临时目录。运行时无需安装 Python。构建剔除测试框架、Tk、未使用的 bz2/lzma/zstd 压缩库，并移除 Python 文档字符串；保留 HTTPS 和自定义探测能力。原生托盘不加载 WebView2 程序集，窗口关闭后所有网页进程释放。前端无持续动画，隐藏页面停止轮询，后台按检测间隔休眠。

发布仅分享 `dist/NJUSTWiFi-3.7.0-Windows-x64.zip` 或源码 ZIP，禁止直接压缩整个开发目录。桌面包中的 `NJUSTWiFi.exe` 是入口，`NJUSTWiFiWindow.exe` 和 `NJUSTWiFiBackend.exe` 以及 DLL、`_internal` 均需保留。WebView2 SDK 固定版本和 SHA256 校验，发布包保留其许可证。

日志按本机时区显示完整日期和时间（`YYYY-MM-DD HH:mm:ss`），支持按显示的日期筛选，内容在日志页内部滚动。

测试与演示需指定独立数据目录，例如 `python -B app.py --demo --serve --data-dir .tmp/demo --port 18090`。演示模式不连接或切换实际 Wi-Fi，不执行校园认证。

## 迁移说明

旧版的账号与基础设置迁入当前用户数据目录；旧虚拟环境、浏览器缓存、日志和历史副本不会加入发布包。程序守护在界面中支持添加、浏览选择、移除、清空和管理员启动设置，复用已有任务；发布包默认没有个人程序配置。日志支持筛选、清空和打开目录。网络及每个守护程序各保留一条当前正常状态，显示持续天、时、分（不足一分钟显示秒），持续正常只更新同一条时长，不新增例行检测记录。断网、认证、切换网络或程序重新启动时记录实际操作，历史正常时长结束后固定。只在日志页可见时更新时长文字；后台每轮检查将最近 100 条日志写为有界快照，不按秒写盘。暂停监控会结束计时，程序重开后不会把停机时间算为正常时长；旧版连续正常记录会合并，重连操作保留。高级设置保留 HTTP 超时、自定义探测和显示认证页面。

已有 DPAPI 凭据首次运行会自动转为 `credentials.json`；之后不再加密。个人账号文件始终保存在用户数据目录，发布包排除这些文件。
